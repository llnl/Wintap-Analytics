# Feature Work Template

Feature work lives under `wiki/work/<feature-slug>/`.

Required artifacts:
- `brief.md`
- `references.md`
- `design.md`
- `implementation_plan.md`
- `verification.md`

Optional artifacts:
- `spike.md`
- `dev_handoff.md`
